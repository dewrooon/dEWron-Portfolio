# dEWron — портфолио

Портфолио frontend-разработчика. Сайт создан на React и Vite, стили организованы по методологии БЭМ.

## Как запустить

```sh
npm install
npm run dev
```

Если PowerShell запрещает запуск скриптов, используйте `npm.cmd` вместо `npm`.

## Как собрать проект

```sh
npm run build
npm run preview
```

Готовая версия сайта появится в папке `dist/`.

## Структура проекта

- `src/App.jsx` — состав страницы.
- `src/components/` — навигация, подвал и общие элементы интерфейса.
- `src/sections/` — разделы портфолио и их стили.
- `src/index.css` — основные переменные дизайна, сброс стилей и общие правила.
- `public/` — статические файлы сайта.

Карточки услуг, проектов и технологий формируются из списков данных в соответствующих разделах. Контактная информация находится в `src/sections/Contact/Contact.jsx`.

Некоторые проекты ещё находятся в разработке: их изображения пока служат концептами. Supabase используется для хранения проектов и постепенно осваивается как инструмент.

На сайте есть мобильное меню, поддержка клавиатурной навигации и ссылка для перехода сразу к основному содержимому. Анимации учитывают системную настройку `prefers-reduced-motion`. Контактные ссылки открывают Telegram и почтовое приложение.

## Страницы и навигация

Маршруты настраиваются с помощью React Router DOM в `src/router/router.jsx`:

- `/` — главная страница портфолио;
- любой неизвестный адрес — страница «Не найдено».

`src/layouts/SiteLayout/SiteLayout.jsx` задаёт общую шапку, подвал и место для содержимого страницы. Чтобы добавить страницу, создайте её в `src/pages/` и добавьте маршрут в `src/router/router.jsx`. Для переходов внутри сайта используйте `Link`, для внешних сайтов и электронной почты — обычные ссылки.

Ссылки на разделы, например `/#projects`, работают и с других страниц. При переходе сайт автоматически прокручивает страницу к нужному разделу.

При публикации настройте сервер так, чтобы для адресов приложения, которые не соответствуют отдельным файлам, он возвращал `index.html`. Это позволит открывать и обновлять внутренние адреса напрямую.

## Проекты в Supabase

Раздел проектов загружает записи из существующей таблицы `projects` с помощью `src/services/projects.js`. На сайте отображаются только опубликованные записи (`is_published = true`): сначала избранные (`is_featured = true`), затем остальные — от новых к старым (`created_at`).

Таблице нужны поля `title`, `description`, `image_url`, `project_url`, `github_url`, `technologies`, `is_published`, `is_featured` и `created_at`. В `technologies` можно хранить список или строку со значениями, разделёнными запятыми. Если указана ссылка на сайт, в карточке появится кнопка для его просмотра. Ссылка на GitHub показывается только для адресов HTTP или HTTPS. Если изображение или название не заданы, сайт использует нейтральную обложку или подпись «Проект». Тестовые проекты в коде не предусмотрены.

Чтобы посетители видели проекты, в Supabase должны быть опубликованные записи и настроен доступ на чтение через RLS. Политика базы данных должна разрешать анонимным посетителям читать только опубликованные записи: фильтра на стороне сайта для защиты данных недостаточно. Эта инструкция не меняет схему базы и её политики.

## Управление проектами

Откройте `/admin` и войдите через Supabase Auth. После проверки прав администратора можно просматривать проекты и черновики, добавлять, редактировать, публиковать, скрывать и удалять записи. Удаление нужно подтвердить. Избранным можно сделать только опубликованный проект. Изображения добавляются по ссылке — загрузки файлов в Supabase Storage нет.

Для работы редактора таблица должна автоматически заполнять `id` и `created_at` при создании записи. В RLS настройте для администратора доступ на чтение, добавление, изменение и удаление. Проверку прав важно выполнять именно в политиках базы данных. Сайт считает сохранение или удаление успешным только тогда, когда база возвращает изменённую запись.

- `src/pages/Admin/Admin.jsx` — панель управления и её разделы.
- `src/pages/Admin/components/` — вход, список проектов и форма редактирования.
- `src/pages/Admin/useAdminAccess.js` — проверка входа и прав доступа.
- `src/pages/Admin/projectForm.js` — подготовка и проверка данных формы.
- `src/services/adminProjects.js` — запросы для управления проектами.

Проверить форму можно командой `node --test src/pages/Admin/projectForm.test.js`.
